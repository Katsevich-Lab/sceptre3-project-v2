# Superseded collaborator-writeup scripts (archived 2026-07)

when §3 was unified on the single guide ENO1 and the "other cell types" (EndoC/CD4) /
cross-dataset material was removed. They are kept for provenance only; nothing in the current
writeup references them. Their orphaned output figures/CSVs are in `results/_archive/`.

- collab_dose_response_fig.R          -> dose_response.png (old flawed pooled aggregate)
- collab_ramac_fig.R                  -> ramac_ambient_fit.png (RAMAC low-mode fit, replaced by ENO1)
- collab_ramac_violin.R               -> ramac_expression_violin.png (RAMAC knockdown, replaced by ENO1)
- collab_other_celltypes_gap_fig.R    -> gap_hist_endoc_cd4.png, ambient_fit_endoc_cd4.png
- collab_dose_response_aggregate_other.R -> dose_response_aggregate_other.png (EndoC/CD4 aggregate)
- collab_violin_other.R               -> expression_violin_other.png (EndoC/CD4 single-guide violins)
- guide_histograms_pdf.R              -> guide_histograms_109.pdf (109-guide diagnostic PDF)
